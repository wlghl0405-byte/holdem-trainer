# 홀덤

텍사스 홀덤 학습용 게임. 혼자 봇과 연습하거나, 친구와 온라인으로 칠 수 있다.

버전 기록은 [CHANGELOG.md](CHANGELOG.md)에 있다.

## 파일

| 파일 | 역할 |
|---|---|
| `engine.js` | 족보 판정·승률·아웃츠·사이드팟 계산 (브라우저·Node 공용) |
| `table.js` | 테이블 진행(딜링·베팅·쇼다운·봇). 브라우저와 서버가 같은 코드를 쓴다 |
| `index.html` | 화면. 혼자 연습 모드 + 친구와 온라인 모드 |
| `server.js` | 온라인 서버(Node + ws). 방 관리, 덱 보관, 각 접속자에게 자기 패만 전송 |
| `홀덤트레이너.html` | `node build-portable.js`로 만든 단일 파일(혼자 연습 전용, 어디서든 열림) |
| `main.js` | Electron 실행용 (`npm run electron`) |

## 실행

```
npm install            # 최초 1회 (ws 설치)
npm start              # 서버 실행 → http://localhost:8080
npm test               # 엔진·게임 흐름·온라인 검증
```

브라우저로 `index.html`을 직접 열면 혼자 연습만 된다. 온라인은 서버 주소가 필요하다.

## 온라인으로 치는 방법

1. 방장이 서버 주소를 열고 설정창에서 **친구와 온라인** → 이름 입력 → **새 방 만들기**
2. **초대 링크 복사**를 눌러 카톡으로 보낸다 (`https://…/?room=ABCD`)
3. 친구는 링크를 눌러 이름만 넣으면 그 방에 들어온다. 이름은 폰에 저장돼 다음부터는 링크만 누르면 된다
4. 방장이 시작 칩·최소 베팅·차례 제한 시간을 정하고 **게임 시작**. 봇을 섞으려면 **봇 추가**
5. 최대 8명. 난이도는 하수·중수·고수·프로·섞기, 차례 제한 시간은 3·5·10초·무제한
6. **파산**: 봇은 파산하면 테이블을 떠난다. 사람은 파산하면 다음 핸드에 시작 칩의 **50%**(처음), 그 뒤로는 파산할 때마다 **10%**로 계속 부활한다(영영 파산 없음). 결과 카드와 알림으로 얼마로 다시 시작하는지 보여준다
7. **자리 비움**: 화면을 떠나거나(다른 앱·화면 잠금) 접속이 끊기면 자동으로 자리 비움이 되어 카드를 받지 않는다. 돌아오면 같은 자리로 복귀하고 자리 비움도 자동 해제된다. 자리는 방 나가기를 누르거나 방장이 내보내기 전까지 남아 있다(사람이 모두 끊긴 방은 30분 뒤 정리)
8. 폰에서는 하단 탭 대신 헤더의 **족보**·**어드바이저** 버튼이 팝업으로 뜨고, 채팅과 이모지는 테이블 아래 독에서 바로 보낸다

베팅은 버튼으로 한다: 폴드 · 체크/콜 · 삥(최소) · 쿼터 · 하프 · 풀 · 따당 · 올인. 채팅과 이모지는 사이드바(모바일은 하단 채팅 탭)에서.

## 무료로 서버 올리기

### 방법 1. Render (권장, 카드 등록 없음)

1. https://render.com 가입 (GitHub 계정으로)
2. Dashboard → **New → Blueprint** → 저장소 `wlghl0405-byte/holdem-trainer` 선택 → 자동으로 `render.yaml`을 읽어 생성
3. 몇 분 뒤 `https://holdem-trainer-xxxx.onrender.com` 같은 주소가 나온다. 이 주소를 친구에게 보내면 된다
4. 코드를 고치면 `git push`만 하면 자동으로 다시 배포된다

무료 서비스는 15분 동안 아무도 안 쓰면 잠든다. 처음 여는 사람이 30초쯤 기다리면 깨어난다. 방 정보는 서버 메모리에만 있으므로 잠들면 방은 사라진다(치는 도중에는 안 잠든다).

### 방법 2. 내 PC에서 서버 켜고 임시 주소 열기

Render 없이 당장 해 보려면:

```
npm start
cloudflared tunnel --url http://localhost:8080
```

`cloudflared`(https://github.com/cloudflare/cloudflared/releases, 무료·가입 불필요)가 `https://xxxx.trycloudflare.com` 주소를 출력한다. 그 주소를 친구에게 보낸다. PC를 끄면 서버도 꺼지고, 주소는 켤 때마다 바뀐다.

### GitHub Pages 주소로 열었을 때

`https://wlghl0405-byte.github.io/holdem-trainer/`는 정적 파일만 있어 혼자 연습만 된다. 온라인은 위 서버 주소로 접속한다(설정창에 서버 주소 입력칸이 나온다).

## 홈 화면에 추가 (앱처럼 쓰기)

서버 주소를 사파리(아이폰) 또는 크롬(갤럭시)으로 열고 **홈 화면에 추가**. 전체 화면으로 열리고 아이콘이 생긴다. 앱스토어 없이 두 기종 모두 된다.
